# Credit Card Approval Prediction

A machine learning project developed during my AI/ML internship at SmartBridge to predict credit card approval based on applicant financial and employment attributes.

## Project Overview

The system uses machine learning techniques to predict whether a credit card application should be approved or rejected based on the applicant's provided information.

## Key Features

- Preprocessed applicant financial and employment data for machine learning.
- Developed a Random Forest classification model for credit card approval prediction.
- Implemented feature scaling and model serialization for deployment.
- Built a Flask web application to accept applicant details and generate predictions.
- Integrated the trained model with the web interface for real-time inference.
